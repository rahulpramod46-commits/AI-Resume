# AI Resume

AI Resume is a browser frontend with an Express backend for uploading and analyzing resumes.

## Project structure

- `Frontend/` contains the static HTML, CSS, JavaScript, and images.
- `Backend/` contains the Express server and resume processing code.

## Run locally

1. Install backend dependencies:

   ```powershell
   cd Backend
   npm install
   ```

2. Configure the backend in `Backend/.env`.

3. Start the server:

   ```powershell
   npm start
   ```

4. Open `Frontend/index.html` in a browser.

Generated uploads and environment files are intentionally excluded from Git.
